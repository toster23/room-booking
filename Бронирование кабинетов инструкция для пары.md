# Бронирование кабинетов: проект в паре через GitHub

Что получится

Веб-приложение: выбираете дату, видите занятые кабинеты и бронируете свободное время. Если время пересекается с чужой бронью, сервер отвечает ошибкой, а страница показывает её пользователю.

- **Бэкендер** пишет сервер на Node.js и TypeScript.
- **Фронтендер** пишет страницу на HTML и JavaScript.
- Оба работают в одном репозитории на GitHub, каждый в своей ветке, и проверяют код друг друга через Pull Request.

| Этап | Что делаем | Кто |
| --- | --- | --- |
| 1 | Репозиторий и правила | вместе |
| 2 | Контракт API | вместе |
| 3 | Сервер и страница | параллельно |
| 4 | Подключаем страницу к серверу | вместе |
| 5 | Pull Request, ревью, слияние | друг другу |

## Этап 1. Репозиторий

1. На github.com нажмите **New**. Название репозитория: `room-booking`. Поставьте галочку **Add a README file**, в списке `.gitignore` выберите **Node**, нажмите **Create repository**. Файл `.gitignore` нужен, чтобы папка `node_modules` (тысячи файлов с библиотеками) не попала в репозиторий.
2. Пригласите напарника: **Settings → Collaborators → Add people**, найдите его по логину.
3. Напарник принимает приглашение (придёт письмо, либо ссылка в уведомлениях GitHub).
4. Оба клонируют репозиторий. В VS Code: **Ctrl+Shift+P → Git: Clone**, вставьте адрес репозитория (кнопка **Code** на странице репозитория), выберите папку, затем откройте её.

Папки `backend`, `frontend` и `docs` создавайте по мере работы: Git не хранит пустые папки, они появятся в репозитории вместе с первым файлом.

## Правила работы с Git (прочитайте оба)

1. **В** **`main`** **напрямую не пишем.** Любая работа идёт в своей ветке.
2. Название ветки показывает, что в ней: `docs/api-contract`, `backend/bookings-read`, `frontend/ui`.
3. Коммиты маленькие, сообщение понятное: «Добавлена проверка пересечения броней», а не «правки».
4. Код попадает в `main` только через Pull Request, и его читает напарник.
5. Перед началом работы и после каждого слияния: переключитесь на `main` и обновите её (**Sync Changes** или `git pull`).

Рабочий цикл в терминале VS Code:

```
git switch main
git pull
git switch -c backend/bookings-read
# ... пишем код ...
git add .
git commit -m "Добавлен список кабинетов"
git push -u origin backend/bookings-read
```

Первая команда переходит в `main`, вторая подтягивает свежий код, третья создаёт новую ветку и переходит в неё. После первого `push` дальше хватает просто `git push`. То же самое можно делать кнопками: название ветки внизу экрана, панель Source Control, Commit, Sync Changes.

## Этап 2. API

Сначала договариваемся, потом пишем. Работа с API записывается в файл `docs/API.md` в ветке `docs/api-contract`. Напарник проверяет его в Pull Request, и только после слияния начинается код.

Ниже пример заполненного файла API: по нему можно сверить, что получилось у пары.

**Что хранится.** Кабинет: `id`, `name`. Бронь: `id`, `roomId`, `date` (формат `ГГГГ-ММ-ДД`), `start` и `end` (формат `ЧЧ:ММ`), `name` (кто бронирует).

| Метод и адрес | Что делает | Успех | Ошибки |
| --- | --- | --- | --- |
| `GET /api/rooms` | список кабинетов | 200 |  |
| `GET /api/bookings?date=2026-11-03` | брони (дата необязательна) | 200 |  |
| `POST /api/bookings` | создать бронь | 201 | 400, 404, 409, 422 |
| `DELETE /api/bookings/{id}` | отменить бронь | 204 | 404 |

Запрос на создание брони:

```
{ "roomId": 1, "date": "2026-11-03", "start": "10:00", "end": "11:30", "name": "Анна" }
```

Ответ при успехе (201): та же бронь с добавленным полем `id`.

Ошибка всегда приходит в виде `{ "error": "текст" }`:

- **400** тело запроса не является корректным JSON;
- **404** такого кабинета (или брони при удалении) нет;
- **409** кабинет в это время уже занят;
- **422** неверные данные: пустое имя, неверный формат даты или времени, конец не позже начала.

Реализуйте его по этапам, которые отмечены в комментариях: сначала весь код до **ЭТАП 1** включительно, запустите и проверьте, сделайте коммит и первый Pull Request. Потом добавьте **ЭТАП 2** (создание брони) и **ЭТАП 3** (отмена) во втором Pull Request.

```
import { createServer, IncomingMessage, ServerResponse } from "node:http";

// ===== Типы данных =====

interface Room {
  id: number;
  name: string;
}

interface NewBooking {
  roomId: number;
  date: string;   // "2026-11-03"
  start: string;  // "10:00"
  end: string;    // "11:30"
  name: string;   // кто бронирует
}

interface Booking extends NewBooking {
  id: number;
}

// ===== Данные (хранятся в памяти, при перезапуске сбрасываются) =====

const rooms: Room[] = [
  { id: 1, name: "Кабинет 101" },
  { id: 2, name: "Кабинет 102" },
  { id: 3, name: "Лекционный зал" },
];

const bookings: Booking[] = [];
let nextId = 1;

// ===== Вспомогательные функции =====

const DATE_RE = /^\d{4}-\d{2}-\d{2}$/;
const TIME_RE = /^([01]\d|2[0-3]):[0-5]\d$/;

// Заголовки CORS: без них браузер не покажет странице ответ сервера
const CORS_HEADERS = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Methods": "GET, POST, DELETE, OPTIONS",
  "Access-Control-Allow-Headers": "Content-Type",
};

// Отправляет ответ: статус и (необязательно) данные в формате JSON
function send(res: ServerResponse, status: number, data?: unknown): void {
  if (data === undefined) {
    res.writeHead(status, CORS_HEADERS);
    res.end();
    return;
  }
  res.writeHead(status, {
    ...CORS_HEADERS,
    "Content-Type": "application/json; charset=utf-8",
  });
  res.end(JSON.stringify(data));
}

// Читает тело запроса и превращает его из текста в объект
async function readJson(req: IncomingMessage): Promise<unknown> {
  const chunks: Buffer[] = [];
  for await (const chunk of req) {
    chunks.push(chunk as Buffer);
  }
  return JSON.parse(Buffer.concat(chunks).toString("utf-8"));
}

// Проверяет данные брони. Возвращает либо ошибку, либо готовую бронь
function validate(data: unknown): { error: string } | { value: NewBooking } {
  if (typeof data !== "object" || data === null) {
    return { error: "Тело запроса должно быть объектом" };
  }
  const d = data as Record<string, unknown>;
  const roomId = d.roomId;
  const date = d.date;
  const start = d.start;
  const end = d.end;
  const name = d.name;

  if (typeof roomId !== "number") return { error: "roomId должен быть числом" };
  if (typeof name !== "string" || name.trim() === "") return { error: "Укажите имя" };
  if (typeof date !== "string" || !DATE_RE.test(date)) return { error: "date: формат ГГГГ-ММ-ДД" };
  if (typeof start !== "string" || !TIME_RE.test(start)) return { error: "start: формат ЧЧ:ММ" };
  if (typeof end !== "string" || !TIME_RE.test(end)) return { error: "end: формат ЧЧ:ММ" };
  if (end <= start) return { error: "Конец должен быть позже начала" };

  return { value: { roomId, date, start, end, name: name.trim() } };
}

// Занят ли кабинет в это время?
// Два промежутка пересекаются, если каждый начинается раньше, чем заканчивается другой
function isBusy(b: NewBooking): boolean {
  return bookings.some(
    (x) => x.roomId === b.roomId && x.date === b.date && b.start < x.end && b.end > x.start
  );
}

// ===== Сервер: здесь разбираем, какой запрос пришёл =====

const server = createServer(async (req, res) => {
  try {
    const url = new URL(req.url ?? "/", "http://localhost");
    const path = url.pathname;
    const method = req.method ?? "GET";

    // Браузер перед POST и DELETE сначала присылает "разведывательный" запрос OPTIONS
    if (method === "OPTIONS") return send(res, 204);

    // ЭТАП 1. Список кабинетов
    if (method === "GET" && path === "/api/rooms") {
      return send(res, 200, rooms);
    }

    // ЭТАП 1. Список броней (можно отфильтровать: /api/bookings?date=2026-11-03)
    if (method === "GET" && path === "/api/bookings") {
      const date = url.searchParams.get("date");
      const list = bookings
        .filter((b) => date === null || b.date === date)
        .sort((a, b) => a.date.localeCompare(b.date) || a.start.localeCompare(b.start));
      return send(res, 200, list);
    }

    // ЭТАП 2. Создать бронь
    if (method === "POST" && path === "/api/bookings") {
      let data: unknown;
      try {
        data = await readJson(req);
      } catch {
        return send(res, 400, { error: "Некорректный JSON" });
      }

      const result = validate(data);
      if ("error" in result) return send(res, 422, result);

      const nb = result.value;
      if (!rooms.some((r) => r.id === nb.roomId)) {
        return send(res, 404, { error: "Кабинет не найден" });
      }
      if (isBusy(nb)) {
        return send(res, 409, { error: "Кабинет в это время уже занят" });
      }

      const booking: Booking = { id: nextId++, ...nb };
      bookings.push(booking);
      return send(res, 201, booking);
    }

    // ЭТАП 3. Отменить бронь
    const match = path.match(/^\/api\/bookings\/(\d+)$/);
    if (method === "DELETE" && match) {
      const id = Number(match[1]);
      const index = bookings.findIndex((b) => b.id === id);
      if (index === -1) return send(res, 404, { error: "Бронь не найдена" });
      bookings.splice(index, 1);
      return send(res, 204);
    }

    send(res, 404, { error: "Not found" });
  } catch (err) {
    console.error(err);
    send(res, 500, { error: "Внутренняя ошибка сервера" });
  }
});

const PORT = 3000;
server.listen(PORT, () => {
  console.log(`Сервер запущен: http://localhost:${PORT}`);
});
```

**3. Запуск.** В папке `backend`:

```
npx tsx watch server.ts
```

Слово `watch` перезапускает сервер при каждом сохранении файла, как `--reload` у uvicorn. Без него изменения не подхватятся.

**4. Проверка.** Запросы GET открываются прямо в браузере: `http://localhost:3000/api/rooms` и `http://localhost:3000/api/bookings`. Для POST откройте второй терминал и выполните (имя пишите латиницей: в старом PowerShell русские буквы в теле запроса могут исказиться):

```
Invoke-RestMethod -Method Post -Uri http://localhost:3000/api/bookings -ContentType "application/json" -Body '{"roomId":1,"date":"2026-11-03","start":"10:00","end":"11:30","name":"Anna"}'
```

Повторите ту же команду: сервер ответит ошибкой 409 «Кабинет в это время уже занят». В PowerShell она выглядит как красный текст, это нормально. Не используйте `curl` в PowerShell: это не настоящий curl, а другая команда с таким же названием.

## Этап 3Б. Страница (делает фронтендер)

Ветка `frontend/ui`, папка `frontend`. Пока сервера нет, страница покажет «Сервер недоступен»: это нормально. Сначала сделайте разметку и форму, а подключайтесь к данным, когда бэкендер сольёт первый Pull Request.

Чтобы увидеть данные, нужен запущенный сервер. Есть два пути: свой (после `git pull` в папке `backend` выполните `npm install`, затем `npx tsx watch server.ts`) или компьютер напарника (см. Этап 4).

Создайте файл `frontend/index.html`:

```

<body>

  </label>

<script>
// Адрес сервера. Если бэкенд запущен у напарника, замените localhost на его IP,
// например "http://192.168.1.45:3000"
const API_BASE = "http://localhost:3000";

const dateEl = document.getElementById("date");
const roomEl = document.getElementById("room");
const startEl = document.getElementById("start");
const endEl = document.getElementById("end");
const nameEl = document.getElementById("name");
const submitEl = document.getElementById("submit");
const bookingsEl = document.getElementById("bookings");
const messageEl = document.getElementById("message");

let roomNames = {};  // id кабинета -> название, например { 1: "Кабинет 101" }

// Сегодняшняя дата в формате ГГГГ-ММ-ДД (в местном часовом поясе)
dateEl.value = new Date().toLocaleDateString("sv-SE");

function showMessage(text) {
  messageEl.textContent = text;
}

// Загружаем список кабинетов и заполняем выпадающий список
async function loadRooms() {
  const res = await fetch(`${API_BASE}/api/rooms`);
  const rooms = await res.json();
  roomEl.innerHTML = "";
  rooms.forEach((r) => {
    roomNames[r.id] = r.name;
    const option = document.createElement("option");
    option.value = r.id;
    option.textContent = r.name;
    roomEl.appendChild(option);
  });
}

// Загружаем брони на выбранную дату и рисуем таблицу
async function loadBookings() {
  try {
    const res = await fetch(`${API_BASE}/api/bookings?date=${dateEl.value}`);
    const bookings = await res.json();
    renderBookings(bookings);
  } catch (err) {
    showMessage("Сервер недоступен: проверьте адрес и что сервер запущен");
  }
}

function renderBookings(bookings) {
  bookingsEl.innerHTML = "";
  if (bookings.length === 0) {
    const tr = document.createElement("tr");
    const td = document.createElement("td");
    td.colSpan = 4;
    td.className = "empty";
    td.textContent = "На эту дату броней нет";
    tr.appendChild(td);
    bookingsEl.appendChild(tr);
    return;
  }
  bookings.forEach((b) => {
    const tr = document.createElement("tr");
    // textContent вместо innerHTML: так чужой текст не сможет внедрить свой HTML-код
    [roomNames[b.roomId], `${b.start}–${b.end}`, b.name].forEach((text) => {
      const td = document.createElement("td");
      td.textContent = text;
      tr.appendChild(td);
    });
    const actionTd = document.createElement("td");
    const btn = document.createElement("button");
    btn.textContent = "Отменить";
    btn.addEventListener("click", () => cancelBooking(b.id));
    actionTd.appendChild(btn);
    tr.appendChild(actionTd);
    bookingsEl.appendChild(tr);
  });
}

async function createBooking() {
  const body = {
    roomId: Number(roomEl.value),
    date: dateEl.value,
    start: startEl.value,
    end: endEl.value,
    name: nameEl.value,
  };
  try {
    const res = await fetch(`${API_BASE}/api/bookings`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(body),
    });
    const data = await res.json();
    if (res.ok) {
      showMessage("");
      loadBookings();
    } else {
      showMessage(data.error);  // например: "Кабинет в это время уже занят"
    }
  } catch (err) {
    showMessage("Сервер недоступен: проверьте адрес и что сервер запущен");
  }
}

async function cancelBooking(id) {
  const res = await fetch(`${API_BASE}/api/bookings/${id}`, { method: "DELETE" });
  // При успехе сервер отвечает 204 без тела, поэтому res.json() здесь не вызываем
  if (res.ok) {
    showMessage("");
    loadBookings();
  } else {
    showMessage("Не удалось отменить бронь");
  }
}

submitEl.addEventListener("click", createBooking);
dateEl.addEventListener("change", loadBookings);

async function start() {
  try {
    await loadRooms();
    await loadBookings();
  } catch (err) {
    showMessage("Сервер недоступен: проверьте адрес и что сервер запущен");
  }
}

start();
// Раз в 3 секунды обновляем таблицу, чтобы видеть брони других людей
setInterval(loadBookings, 3000);
</script>

</body>
</html>
```

Что важно в этом коде:

- `API_BASE` единственное место с адресом сервера, менять нужно только его.
- `textContent` вместо `innerHTML`: чужое имя не сможет подставить в страницу свой HTML-код.
- `res.ok` равно true для кодов 200–299. Иначе показываем `data.error`, то есть текст, который прислал сервер.
- На DELETE сервер отвечает кодом 204 без тела, поэтому `res.json()` там не вызываем.
- `setInterval` раз в 3 секунды обновляет таблицу, так вы видите брони, которые создал напарник.
- При конфликте времени в консоли браузера появится красная строка про код 409. Это не сбой, а ответ «занято», страница при этом показывает понятное сообщение.

Проверка: откройте `index.html` двойным щелчком, нажмите «Забронировать», затем нажмите ещё раз с теми же данными. Второй раз должно появиться «Кабинет в это время уже занят».

## Этап 4. Подключаем страницу к серверу (вместе)

**Вариант А. Один компьютер.** Сервер и страница на одном компьютере, `API_BASE` остаётся `http://localhost:3000`.

**Вариант Б. Два компьютера в одной сети.**

1. Бэкендер узнаёт свой адрес: в терминале `ipconfig`, строка «IPv4-адрес», например `192.168.1.45`. Затем запускает сервер.
2. При первом запуске Windows спросит разрешение для Node.js. Разрешите для частных сетей.
3. Фронтендер в `index.html` меняет адрес: `const API_BASE = "http://192.168.1.45:3000";` и открывает страницу.
4. Проверка до всего остального: фронтендер открывает в браузере `http://192.168.1.45:3000/api/rooms`. Должен показаться список кабинетов.
5. **Перед коммитом верните** **`localhost`**, чтобы чужой адрес не попал в репозиторий.

## Этап 5. Pull Request, ревью и слияние

1. Отправьте ветку на GitHub (`git push`). На странице репозитория появится жёлтая плашка **Compare \& pull request**. Нажмите её.
2. В заголовке коротко напишите, что сделано. В описании: что добавлено и как проверить (например: «Запустить сервер, открыть /api/rooms»). В поле **Reviewers** выберите напарника.
3. Напарник открывает вкладку **Files changed**, читает код и при желании оставляет комментарий к строке (синий плюс слева от номера строки).
4. Затем **Review changes → Approve**, а если есть замечания, **Request changes**.
5. Автор нажимает **Merge pull request → Confirm merge**.
6. Оба выполняют `git switch main` и `git pull`. Для следующего этапа создайте новую ветку.

Что проверять при ревью:

- Код запускается у вас на компьютере.
- Названия понятные, нет лишнего и закомментированного кода.
- Всё совпадает с контрактом `docs/API.md`: адреса, поля, коды ответов.
- В репозитории нет папки `node_modules` и чужих IP-адресов.
- Сообщения коммитов осмысленные.

**Если возник конфликт.** Когда вы оба правили один и тот же файл, GitHub покажет **This branch has conflicts**. Выполните в своей ветке `git pull origin main`. В файле появятся пометки `<<<<<<<` и `>>>>>>>`, а над ними кнопки **Accept Current Change**, **Accept Incoming Change** и **Accept Both Changes**. Выберите нужный вариант вместе с напарником, сохраните файл, сделайте коммит и `git push`.

## Частые проблемы

| Что видите | Причина | Что делать |
| --- | --- | --- |
| В консоли ошибка CORS | Сервер не перезапущен или нет заголовков CORS | Проверить `CORS_HEADERS` в `server.ts`, перезапустить сервер |
| «Сервер недоступен» на странице | Сервер не запущен, неверный IP или порт | Открыть `/api/rooms` в браузере по тому же адресу |
| Адрес в браузере не открывается у напарника | Брандмауэр или Wi-Fi с изоляцией устройств | Разрешить Node.js в брандмауэре, проверить `ping` до напарника |
| Красная строка про 409 в консоли | Это не ошибка: ответ «кабинет занят» | Ничего, страница показывает сообщение |
| Красные подчёркивания в `server.ts` | Нет `tsconfig.json` или `@types/node` | Создать `tsconfig.json`, затем Ctrl+Shift+P → TypeScript: Restart TS Server |
| npm: «выполнение сценариев отключено» | Запрет скриптов в PowerShell | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `git push` отклонён: `fetch first` | В ветке есть чужие коммиты | `git pull`, затем снова `git push` |
| В репозиторий попала папка `node_modules` | Нет `.gitignore` | Добавить `.gitignore` с Node, выполнить `git rm -r --cached node_modules` |
| Изменения в сервере не видны | Сервер запущен без `watch` | Остановить (Ctrl+C) и запустить заново |
