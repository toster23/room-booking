# Контракт API room-booking

## Кабинеты
- **GET /api/rooms** — Список кабинетов (Код: 200)

## Бронирования
- **GET /api/bookings?date=2026-11-03** — Список броней на дату (Код: 200)
- **POST /api/bookings** — Создать бронь (Код: 201)
  - Ошибки: 400 (Некорректный JSON), 404 (Нет кабинета), 409 (Занято), 422 (Неверные данные)
- **DELETE /api/bookings/{id}** — Отменить бронь (Код: 204)
